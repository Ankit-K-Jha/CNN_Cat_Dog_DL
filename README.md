# CNN_Cat_Dog_DL
This is a deep learning mini-project where a model predicts the image as cat or dog.

# Cat vs Dog Image Classification using CNN

This project uses TensorFlow and Keras to classify images
as either Cat or Dog.

## Technologies
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Microsoft Cats vs Dogs dataset from Kaggle.

## Model
Convolutional Neural Network (CNN)

## Result
Training Accuracy: ~79.5%
Validation Accuracy: ~83.2%
